# 源码整理记录 · 2026-10-01

## 整理内容

- 从业务源码移除地址标注、ABI 布局和反编译过程说明；有用的注释改为描述函数行为。恢复依据和未完成部分继续记录在恢复文档及清单中。
- 将 `recovered_types.go` 改为 `application_types.go`，`schema_recovery.go` 改为 `schema.go`；SQL 常量和构建版本使用常规业务命名。
- 合并 `App` 和嵌入状态里的重复字段，使锁、缓存及任务状态各自只有一个实例。
- 统一 JSON 标签、`any`、`byte` 等类型写法；将错误截断、图片大小和像素数量、缓存容量改为有含义的限制常量。
- 整理扫描 SQL 的排版、重定向结果的字段布局和中文集数的分支，移除中文集数函数中不可达的回退逻辑。

## 局部防护

- 代理客户端缓存写入前，在已有锁内初始化可能为空的映射。
- 中文集数函数直接处理负数，按零显示，避免其他调用方传入负值时产生下标越界。
