# 4K 动态登录页

登录页使用金发蓝眼角色的原始关键帧，输出 3840 × 2160、30 fps、静音 H.264 / yuv420p MP4，索引前置。

- `frontend/web/assets/ai-emby-boot-v4-4k.mp4`：7.2 秒完整片头，保留原版标题和扫描显影；原始 v4 文件保留。
- `frontend/web/assets/ai-emby-login-background-v3-4k.mp4`：6.67 秒背景，保留原片黑屏、线条扫描、颜色显现与睁眼节奏，移除片尾黑场。仅播放一次，结束后停在完整睁眼画面。文字由页面渲染在左上方。
- `frontend/web/assets/ai-emby-login-poster-v3-4k.jpg`：4K 睁眼静态封面，仅在减少动态效果、省流量、媒体失败或自动播放受阻时使用。

已逐帧对照用户提供的 `AI-EMBY-boot.mp4`，其 SHA-256 与原始 `ai-emby-boot-v4.mp4` 一致。背景复用原片的扫描线、边缘显影、面部网格、颜色转换、镜头与眼睑时间点：0–2.5 秒扫描显影，2.65–4.4 秒睁眼。按用户要求在原片淡出前结束，角色、大字与登录框保持完整显示；切换标签页或动态效果偏好不会重新播放。正常加载时先显示黑色，不闪现睁眼封面。登录框随标题后段渐入，首次出现后保持可操作。

沿用当前 1672 × 941 人物关键帧，人物图像插值放大；标题、轨道、粒子等由 Canvas 按 4K 输出重新渲染，不宣称人物原图是原生 4K。

桌面左侧偏上保留原片「AI EMBY」大字，登录框置于其下，右侧为人物特写。大字沿用原片 italic 900 / 140px 字号（1920 × 1080 舞台）、逐字勾勒、金属显影与蓝色光晕；按照背景视频铺满屏幕的同一比例缩放。标题单独用 Canvas 渲染，并与背景播放、暂停和结束同步。登录框按实际字形的中心横向居中，排除 Canvas 右侧留白，宽度扩大为上一版的 1.5 倍（286.67–453.33px → 430–680px）。竖屏按可用宽度容纳大字与表单；减少动态效果时显示完整金属标题。保留自定义服务器名称、设备长期登录、浏览器密码自动填充，以及显示密码、登录忙碌状态和卡片内错误提示。

未登录用户直接进入动态登录页。已登录用户仍按原有每标签页一次的规则播放完整片头。背景支持暂停，标签页隐藏时暂停，切换页面时释放视频。减少动态效果或省流量偏好显示封面和静态完整标题、表单，不请求 MP4；媒体失败或自动播放受阻也回退到这一可登录状态。

## 重制

在现有渲染脚本调用末尾添加 `--4k` 输出完整片头，添加 `--login-background` 输出登录背景和封面：

```text
node scripts/render-boot-animation.cjs [Canvas 模块路径] [FFmpeg 路径] --4k
node scripts/render-boot-animation.cjs [Canvas 模块路径] [FFmpeg 路径] --login-background
```

`node scripts/preview-boot-animation.cjs` 启动本机预览。访问 `/` 查看登录页，访问 `/web/boot-preview.html` 播放或下载完整 4K 片头。该服务仅提供前端，账号认证需要实际服务端。
