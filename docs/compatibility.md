# 兼容格式

项目名称、页面品牌、Go 模块及容器中的进程名称统一为 AI Emby。以下内部标识继续用于读取现有状态和通信。

| 格式 | 作用 |
| --- | --- |
| 浏览器会话与主题存储键 | 更新后读取当前设备已有登录及主题；不要求用户再次登录 |
| 设备标识算法、授权端点 | 保持已绑定的机器标识和授权请求有效 |
| 请求头与扫描事务标记 | 与核心服务共享鉴权、播放和数据库触发器语义 |
| 更新包内文件名 | 已安装的宿主机更新服务可继续接收新版本；容器中运行文件使用 AI Emby 名称 |
| Compose 项目名与服务名 | 已有部署沿用自身名称，新部署默认使用 `ai-emby`；更新服务按镜像识别目标服务 |

核心服务的完整源码仍在恢复中，运行文件中的编译信息保持原有字节和 SHA256。函数清单采用项目内相对路径；授权包函数名省略 Go 模块前缀。带地址的完整分析映射保存在本地分析工作区。
